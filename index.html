🧩 Projet APOCLEM – CMS WordPress

📌 Contexte

Le projet APOCLEM est un site web associatif basé sur le CMS WordPress, destiné à la gestion et la diffusion de contenus culturels liés aux orgues de la cathédrale.

⚙️ Technologies utilisées

  • WordPress (CMS)
  • PHP (backend)
  • MySQL (base de données)
  • HTML / CSS

🧠 Fonctionnement technique

Le fichier index.php de WordPress correspond au cœur du système d’administration. Il permet de gérer :

  • Le tableau de bord (dashboard)
  • Les widgets de gestion
  • L’administration des plugins
  • L’affichage des statistiques et contenus

🔐 Compétences mobilisées (BTS SIO)

  • Administration de CMS
  • Configuration serveur web
  • Gestion base de données MySQL
  • Maintenance applicative

🎯 Rôle réalisé

Installation et configuration du CMS, personnalisation du thème, intégration des contenus et gestion des extensions WordPress.
