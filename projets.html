💻 Projet E5 · APOCLEM

📌 Description

Ce projet consiste en la création d'un site web pour l'Association Pour la Promotion des Orgues de la Cathédrale de Laval et de la Mayenne (APOCLEM). L'objectif était de concevoir un site simple, évolutif et rapidement déployable pour soutenir la campagne d'adhésion, tout en étant hébergé sur le site paroissial avec l'URL historique https://www.apoclem.fr.

⚙️ Fonctionnalités

  • Accueil : Présentation de l’association
  • Actualités : Fil d’actualité
  • Documents : Téléchargement (bulletins, flyers)
  • Historique des instruments : orgues de la cathédrale
  • Historique des organistes : biographies + photos
  • Album photographique : concerts et événements
  • Archives : documents historiques
  • Liens : partenaires
  • Membres : accès sécurisé (évolutif)
  • Contact : informations et mentions légales

🧠 Technologies utilisées

  • HTML / CSS / JavaScript
  • Bootstrap (responsive design)
  • WordPress (CMS)
  • MySQL (base de données membres)

🖥️ Architecture technique

Le site repose sur un CMS WordPress permettant la gestion dynamique des contenus. Le backend PHP interagit avec une base MySQL pour l’espace membres.

📦 Installation locale

Prérequis :

  • XAMPP / WAMP / MAMP
  • Navigateur web
